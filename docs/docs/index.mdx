Inertia (`@rootnative/inertia`) is a thin wrapper around `react-native-reanimated`. You write an animation as props on a component: no shared values, no worklets, no `useAnimatedStyle` boilerplate. The vocabulary takes ideas from **Framer Motion** (web) and **react-spring** (cross-platform).

Inertia supports iOS, Android, and web (react-native-web). macOS, Windows, and Electron are not tested. See [Platforms](./installation#platforms).

> **Status:** `0.0.27`. The example app covers the full surface: primitives, per-property transitions, sequences, variants, gestures, `<Presence>`, decay, `<MotionConfig>`, layout, shared elements, and the value-layer hooks. Before `1.0.0`, a minor release can still change the API. The [changelog](https://github.com/rootnative/inertia/blob/main/packages/core/CHANGELOG.md) names each breaking change.

## What you get

- **DX-first.** Animations are props on a component, not shared values, worklets, and `useAnimatedStyle` boilerplate.
- **Per-primitive style inference.** `Motion.View` accepts `ViewStyle` keys, `Motion.Text` accepts `TextStyle` keys, and `Motion.Image` accepts `ImageStyle` keys. There is no shared union fallback, so a wrong prop is a type error.
- **react-spring vocabulary.** A spring config uses `tension`, `friction`, `mass`, and `velocity`. Reanimated's raw `stiffness` and `damping` never appear in the public surface.
- **One `gesture` prop on every primitive.** The sub-states are `pressed`, `focused`, `focusVisible` (W3C `:focus-visible`), and `hovered` (web). There is no `whileTap` or `whilePress` family, and no separate "pressable" variant.
- **Per-primitive tree-shaking.** Subpath imports (`@rootnative/inertia/view`, `/text`, `/image`, `/pressable`, `/scroll-view`) let an app that animates one element skip the rest of the library.
- **Stable worklets.** The factory hashes the resolved `animate` and `transition` objects and memoizes the generated worklet and `useAnimatedStyle`. A re-render with the same values makes no new UI-thread closure.

## Install

Pick your package manager. Yarn is the default, and your choice applies to every install snippet in the docs.

<PackageManagerTabs packages="@rootnative/inertia react-native-reanimated react-native-worklets" />

Then enable the `react-native-worklets/plugin` Babel plugin as the Reanimated [install guide](https://docs.swmansion.com/react-native-reanimated/docs/fundamentals/installation) shows. [Installation](./installation) has a full `babel.config.js`.

## A first animation

```tsx
import { Motion } from '@rootnative/inertia'

export function FadeIn() {
  return (
    <Motion.View
      initial={{ opacity: 0, translateY: 20 }}
      animate={{ opacity: 1, translateY: 0 }}
      transition={{
        opacity: { type: 'timing', duration: 200 },
        translateY: { type: 'spring', tension: 180, friction: 12 },
      }}
    />
  )
}
```

To ship only one primitive, import it from its subpath:

```ts
import { MotionView } from '@rootnative/inertia/view'
```
